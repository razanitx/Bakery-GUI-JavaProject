#  Bakery Order Management System

## Overview

The **Bakery Order Management System** is a Java-based desktop application designed to manage bakery orders through an interactive **Graphical User Interface (GUI)**.

The system allows users to add desserts, manage customer information, view order details, calculate the total cost, and efficiently manage bakery orders. It also includes **file management and data persistence**, allowing order information to be automatically saved and loaded between application sessions.

This project demonstrates the practical use of **Object-Oriented Programming (OOP)**, Java GUI development, file handling, and data persistence.

---

## Features

*  Manage customer details
*  Add and manage desserts
*  Create and manage bakery orders
*  View order details
*  Calculate the total order cost
*  Save order data to a file
*  Load saved order data when the application starts
* Interactive graphical user interface
